AI Policy

Equilibrio AI is the public assistant on www.equilibriorecords.com. It is designed to answer questions about the label, catalog, artists, sessions and how to contact us.

1. How it works

You type a question in the website. The message is sent to our server at /api/chat. The server calls Google Gemini and returns the answer on the same page. The Gemini API key is not published in the browser.

2. What it is for

  • Public information about Equilibrio Records
  • Releases, artists and sessions that are already public
  • Demo and contact guidance

3. What it is not

  • It is not a human A&R manager
  • It is not legal, financial or medical advice
  • It is not a private office for contracts, royalties or unpublished material
  • It may be unavailable when the model is saturated
  • It can make mistakes or omit catalog details

4. What not to paste in the chat

Do not send passwords, IDs, bank data, private contracts, unreleased tracks that must stay confidential, or personal data of other people.

5. Accuracy

If an answer conflicts with the website, the website and a message to equilibriorecs@gmail.com prevail. Equilibrio AI should say when it is not sure.

6. Providers

The assistant is hosted with our website provider and uses Google Gemini to generate text. See the Privacy Policy for data handling.

7. Abuse

We may rate-limit or disable Equilibrio AI if it is used to attack the service, flood the API or extract internal information.
