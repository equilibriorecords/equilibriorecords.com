Security Policy

Equilibrio Records applies reasonable technical and organizational measures to protect this website and the information sent to us. No website can guarantee absolute security.

1. Website protections

  • The site is served over HTTPS
  • The public Equilibrio AI endpoint does not expose the Gemini API key in the browser
  • The key is stored as a server environment variable on the host
  • Security headers are used to reduce common browser attacks
  • Embedded players from SoundCloud and similar services run in isolated frames

2. What you should not send

Do not send through the website, the chat or email:

  • Passwords or access codes
  • Bank details unless we expressly request them by a secure channel
  • Copies of identity documents unless legally required and requested
  • Private contracts or internal label information in Equilibrio AI

3. Demos and files

Demo submissions are received by email. Send only audio or links you have the right to share. We may delete files that look unsafe or unrelated to a music submission.

4. Incidents

If you discover a security issue on www.equilibriorecords.com, write to equilibriorecs@gmail.com with a clear description. Do not publish exploit details publicly until we can review them.
